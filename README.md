# Pet Care (ЛР7)

Front-end фрагмент мобільного застосунку для догляду за домашніми улюбленцями. Реалізовано за макетом Figma (ЛР6): 9 екранів, компоненти дизайн-системи, анімаційні сценарії S1-S9 з ЛР5, навігація за картами потоків.

Навчальний проєкт: курс «Методи проєктування інтерактивних інтерфейсів», Львівська політехніка, 2026.

## Стек

React 19, TypeScript, Vite, react-router-dom (HashRouter), чистий CSS із токенами дизайн-системи, PWA (манифест і service worker).

## Запуск

```bash
npm install
npm run dev        # режим розробки
npm run build      # перевірка типів і збірка в dist/
npm test           # модульні тести (Vitest)
```

Знімки екранів і піксельне порівняння з еталонами Figma (потрібен `npx playwright install`):

```bash
npm run build
npm run test:visual   # звіт у tests/visual/out/summary.json
npm run test:e2e      # сценарії, доступність (axe), кросбраузерність
```

## Службові параметри адреси

| Адреса | Призначення |
| --- | --- |
| `/?frame=device#/` | режим кадру: статус-бар iOS, без анімацій (для порівняння з макетом) |
| `#/sharing?state=invited` | екран «Спільний доступ» у стані «запрошення надіслано» |
| `#/export?state=ready` | екран «Експорт» у стані «файл готовий» |
| `/?theme=dark` | темна тема (токени визначені, екрани не перевірялись) |
